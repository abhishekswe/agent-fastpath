The System 1 Thesis

Why coding agents need a reflex layer

A mental model and talk track for discussing agent-fastpath with colleagues, users, and teams.

The 30-Second Talk Track
"Coding agents are brilliant at deep reasoning, but terrible at reflexes. They burn 35,000 tokens of context and 10 seconds of time answering tiny questions like 'Did this test pass?' or 'Which file defines this route?'.

agent-fastpath is an MCP-native decision layer. It gives coding agents a System One reflex arc: instant regex rules in <1ms, micro-model judgments via TypeSafe Jev in 300ms, and a calibrated confidence gate that knows when to say 'I am not sure, ask the human.' It cuts context bloat by 98% and prevents agents from guessing."

Anticipated Questions & Objections
Why not just prompt Claude or GPT-4o? ▼
Context window dilution. Loading dozens of files into Claude's working context just to find a single route handler degrades the agent's attention on your actual instructions, and every subsequent turn costs 10x more. Fastpath does the heavy reading server-side.
Why not just write bash scripts or grep? ▼
Exact bash patterns work great—and Fastpath actually uses deterministic regex first (<1ms)! But bash cannot understand fuzzy semantic concepts like: "Does this requirement contradict our policy?" Fastpath combines deterministic rules with Jev's System 1 neural judgments.
What happens when the model is uncertain? ▼
The Confidence Gate. If confidence falls below 0.55 or the margin between the top two choices is under 0.15, Fastpath returns status: "escalate" with recommendedAction: "ask_user". It never hallucinates an ungrounded guess.
Does my source code leave the machine? ▼
The MCP host never receives bloated files. Before excerpts leave for semantic ranking, secrets (AWS keys, OpenAI tokens, passwords) are automatically redacted. Files are bounded to 64KB reads and max 4,000 char excerpts. Traces are stored strictly in-memory (never written to disk).
Security Invariants

Defensive by default

Because tool inputs and external logs can be adversarial, agent-fastpath enforces strict operator-controlled boundaries.

2-Layer SSRF Defense
Browser navigation blocks private IP ranges, link-local, loopback, and metadata endpoints (169.254.169.254). Enforced via pre-navigation hostname resolution AND an inline Chromium proxy to stop DNS rebinding.
Irreversible Action Gate
Buttons matching destructive verbs (delete, buy, pay, drop, merge) are marked IRREVERSIBLE. The browser tool refuses execution unless explicitly granted allowIrreversible: true.
Bounded 64KB File Reads
Triage reads only within operator-allowed directory roots after resolving symlinks. Files are capped at 64KB, and at most 4,000 characters are sent for semantic relevance scoring.
Secret Redaction & RAM Traces
AWS keys, GitHub tokens, Bearer headers, and passwords are scrubbed before reaching Jev or traces. Traces exist solely in an in-memory ring buffer (capped at 500) and are never written to disk.
