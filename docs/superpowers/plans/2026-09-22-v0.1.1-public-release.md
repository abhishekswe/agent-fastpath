> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce a clean, documented, reproducibly tested `agentctl-fastpath` v0.1.1 release candidate containing the FP1–FP6 fixes without exposing local credentials or private-repository benchmark data.

**Architecture:** Keep the runtime architecture unchanged. Strengthen behavior at its existing boundaries: deterministic classification in core, safe status/action synthesis in the router, browser evidence and semantic verification in the MCP tool, and release validation in tests and CI. Keep the npm artifact minimal while publishing source, tests, benchmark methodology, and security documentation on GitHub.

**Tech Stack:** Node.js 20/22/24, TypeScript 5.7, Node test runner, MCP SDK, Playwright Chromium, esbuild, npm workspaces, GitHub Actions.
